# Synthetic sample data

Generated by `python3 scripts/generate_synthetic_data.py --seed 42 --today 2026-04-15` (deterministic for a given seed).
Nothing here comes from a real business: brand "DemoBrand", 24 SKUs `DEMO-001..024`, generic product names, random prices,
costs, volumes, nine generic warehouse clusters, three CPC campaigns, three promotions, planned cash events and parameters.

Gaps injected on purpose (to show the freshness logic): orders by SKU loaded only up to D-2 and today's run FAILED (HTTP 429);
pay-per-order report missing for D-1; accruals lag 3 days; two days where postings have fewer units than the orders source;
the first two weeks of postings have no second source.
