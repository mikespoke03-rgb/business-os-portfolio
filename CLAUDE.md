## Claude Code

`AGENTS.md` — единственный источник правил для Codex и Claude Code. Этот файл импортирует его и добавляет только особенности Claude Code.

- Изменения в `sql/`, `scripts/render_report.js`, `llm/` начинать в plan mode: план, затем падающий тест, затем правка.
- Без вопросов можно: читать файлы, запускать `python scripts/check.py`, `npm test`, `node llm/eval.js` (повтор записанных ответов).
- Только с разрешения владельца: Docker, любые сетевые вызовы, коммиты.
- Не добавлять API-клиент модели: AI-слой — Grok Bot (настольный ассистент владельца). Не читать `.env` и файлы с ключами; ключи вводит владелец, они хранятся вне репозитория.
- Перед «готово»: `python scripts/check.py` (и `--sql` на демо-базе), `npm test`, `python scripts/scan_secrets.py`; в отчёт вставлять фактические строки результата, а не пересказ.
